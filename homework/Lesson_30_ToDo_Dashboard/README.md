# ToDo Dashboard

Front-end აპლიკაცია, რომელიც იღებს todo ჩანაწერებს
[jsonplaceholder.typicode.com/todos](https://jsonplaceholder.typicode.com/todos)-დან და აჩვენებს
სიას საძიებო ველით, ფილტრებით (userId, completed) და პაგინაციით. თითოეულ todo-ს ჰყავს
ცალკე დეტალური გვერდი.

## გაშვება

```bash
cd homework/Lesson_30_ToDo_Dashboard
python3 -m http.server 8000
```

შემდეგ გახსენით ბრაუზერში: http://localhost:8000/index.html

გასაჩერებლად ტერმინალში დააჭირეთ `Ctrl+C`.
